# 実機に合わせた構成

ユーザー確認: G1を吊り具で支持。Inspire Handの銘板はRH56DFQ。

本体は29軸、左腕7軸。公式URDFは
vendor/unitree_ros/robots/g1_description/g1_29dof_rev_1_0_with_inspire_hand_DFQ.urdf。
取得元: https://github.com/unitreerobotics/unitree_ros/tree/master/robots/g1_description
コミット: 5994d4faef0a9cadd3287f8de0199a67eeb2a259。
DFQとFTPでは手のリンク形状・取付け・センサーリンクが異なる。
G1のmode_machine=5だけではハンド型番は判別できない。

## 実際に受信できた情報

| 部位 | 情報 | 状態 |
| --- | --- | --- |
| G1 | 29関節の角度q、速度dq、推定トルクtau_est | rt/lowstateで受信 |
| G1 | モーターモード、温度2値、電圧、エラーフラグ | 受信・記録 |
| G1 IMU | 姿勢RPY、クォータニオン、角速度、加速度 | 受信 |
| D435I | RGB 1920×1080 | PCへ継続配信 |
| D435I | デプス1280×720、深度スケール、内部パラメータ、深度→カラー変換 | 実機から取得 |
| 左RH56DFQ | 6駆動軸の指位置、力の生値、電流、エラー、温度 | /dev/ttyUSB2へ読み取り要求を送り受信 |
| MID360 | livox_imu、livox_pc、odomプロセス | 実機で起動を確認。点群の受信は別途確認 |

HG LowStateには35個のモータースロットがあるが、G1本体29軸と同義ではない。
IDLには関節加速度ddq、センサー生情報、リモコン40バイト、tick等もある。
値の意味・有効性を確認せず、接触判定に使わない。

tau_estはモーターの推定トルクであり、手首6軸力覚センサーの測定ではない。
指の力は未校正で、無負荷でも大きい正負の値が出ている。
現時点で絶対的な把持力・接触有無の判定には使えない。
指面全体の触覚画像と6本の指力は別の情報。FTP対応と誤認して触覚配信を使わない。

カメラの光学座標からロボット基準への変換はURDF由来の公称値。
実機での校正・投影一致はまだ未検証。
Jetsonの実時計がPCと同期していないため、順序・通信監視には単調時計を使用。
